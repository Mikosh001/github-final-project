# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Open an issue to report a bug or propose an improvement.
2. Fork the repository and create a branch for your change.
3. Make a focused change, and check that the calculator still works.
4. Submit a pull request with a clear explanation of your change.

Please follow the community standards in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
